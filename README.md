# SaleFlow — Система контроля продаж для менеджеров и владельцев бизнеса

**SaleFlow** — это инструмент, который показывает, где ваши менеджеры теряют клиентов, и даёт готовые ответы, которые увеличивают вероятность сделки.

## Что вы получаете

- **Анализ каждой переписки** по 27 критериям продаж
- **Выявление главных причин потери сделок** — не просто ошибки, а конкретные барьеры покупки
- **Sales Health Score** — агрегированный показатель здоровья ваших продаж
- **Персональные рекомендации** — что написать клиенту прямо сейчас
- **История прогресса** — отслеживайте рост навыков ваших менеджеров
- **Pro-функции** — безлимитные анализы, персональный тренер, динамика развития

## Для кого

- Владельцы бизнеса, которые хотят контролировать качество работы отдела продаж
- Руководители отделов продаж, которым нужна объективная оценка менеджеров
- Фрилансеры и предприниматели, которые сами ведут переговоры

## Как работает

1. Вы вставляете диалог с клиентом (в формате `Клиент: ...` / `Вы: ...`)
2. Система анализирует его по 27 критериям и выявляет слабые места
3. Вы получаете отчёт:
   - Риск потери сделки
   - Причины
   - Следующий шаг
   - Пример идеального ответа
4. Вы исправляете ошибки и закрываете больше сделок

## Тарифы

- **Free** — 5 анализов в месяц, базовый отчёт
- **Pro** — безлимитные анализы, история прогресса, экспертные ответы
- **Business** — командный доступ, рейтинг менеджеров, отчёты для руководителя (в разработке)
